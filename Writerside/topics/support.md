# Support

Use this page if you need help with API access, import credentials, payload validation, or exported data.

## Contact

For support, contact [Johan van der Heide](mailto:johan.van.der.heide@itea4.org).

## Typical support topics

- requesting or renewing API credentials
- clarifying the project import JSON structure
- troubleshooting authentication or Bearer token issues
- checking import results in the PA portal
- questions about Parquet or CSV exports for data lake delivery
